# Cube Design System — Claude AI Guide

Welcome to the Cube Design knowledge base.
This folder contains everything Claude needs to help you design
and prototype screens that match the Cube BI design system exactly.

---

## What is this?

Cube Design is the shared design system for Folio — our BI product.
It includes a color palette, spacing grid, typography scale, icon library,
and UI patterns used across every screen in the product.

When you upload these files to a Claude.ai Project, Claude will follow
our design rules automatically — consistent colors, spacing, layout,
and component patterns every time.

---

## How to set up your Claude Project

1. Go to [claude.ai](https://claude.ai) and open **Projects**
2. Create a new project — name it **Cube Design**
3. Upload all `.md` files from this folder as project knowledge
4. Start a new conversation inside the project
5. Claude will now follow Cube Design rules in every response

## How to use Claude for design work

Once your project is set up, you can ask Claude to:

- **Describe a screen layout** — Claude will follow Cube Design structure
- **Review a design** — Claude will flag anything that breaks our rules
- **Suggest a pattern** — Claude will recommend the right component
- **Write HTML/CSS** — Claude will use exact token values, not approximations
- **Generate a prompt** — Claude will help you write a better brief

---

## Ground rules for prompting

- Always mention the screen name (e.g. "the Reports screen")
- Reference the user role if relevant (e.g. "for a Finance Manager")
- Say what the user is trying to do, not just what you want built
- If something looks wrong, paste the output back and ask Claude to fix it
